🪄 Motion Refinement

프로젝트 기간: 2025. 12 - 2026. 01

Foot skating과 penetration 등 아티팩트를 해소해 모션의 품질을 향상시킬 수 있는 motion refinement 모델을 설계했습니다. - Text-to-motion 품질을 개선하기 위해 시작한 프로젝트였으나, 높은 호환성과 가벼운 아키텍쳐로 인해 다른 모델의 후처리 로직으로도 활용 가능합니다. - VQVAE, RQVAE, diffusion model 기반 refinement model을 설계하고 품질을 비교했습니다. - 조직 내부에서 사용 가능한 공통 RQVAE motion tokenizer 베이스라인을 설계했습니다. - 추론 시 residual layer 개수를 지정해 모션 보정 강도를 지정할 수 있습니다.

📍 풀어야 했던 문제

- As-is : 생성 모델을 활용한 모션 결과물은 신체를 뚫거나 떨림이 발생하는 등 artifact가 존재 - 학습 분포에서 먼 local rotation 정보가 생성되는 경우 몰입을 저해할 수 있음 - 서비스중인 개별 모션 모델들의 artifact를 각각 개선하는 방식은 장기적인 유지보수 cost가 필요하며 복잡도가 높음 - To-be : 기존 모델과 호환 가능한 모듈형 모션 보정 모델 확보 - 모델의 학습 범위를 local rotation으로 한정한 motion tokenizer 형태의 보정 모델 확보 - 빠른 샘플링과 가벼운 아키텍쳐를 특징으로, 기존 모델의 후처리 로직으로 바로 활용 가능

📍 업무 수행 내용

- VQVAE, RQVAE, diffusion model 기반 모션 보정 모델 PoC 진행 : 모델이 배운 자연스러운 모션 분포로 입력 모션을 변화시켜 보정 유도 - VAE 계열 : 1D Convolution의 경계 구간에서 생길 수 있는 drift를 완화하기 위해 padding 적용, encoder-decoder 통과 후 padding 구간을 제거하고 리턴 - Diffusion model : 입력 모션에 gaussian noise를 약한 강도로 더한 후, 10 step denoising을 반복해 리턴 - Motion canonicalize → local rotation tokenizing 진행 - 모션 생성 모델의 어색함은 global translation이 아니라 local rotation에서 기인한다는 점에서 착안, 모델이 local 정보만 안정적으로 학습하도록 유도 - 예) Blender 좌표계 기준, 'y축으로 2m 걷기' 와 '-y축으로 2m 걷기' 를 별도 학습 대상 정보로 분리하지 않고 '걷기' 포즈 정보를 효과적으로 학습 - 추론시 global translation은 원본 모션이 가진 pelvis joint의 translation 정보를 그대로 사용, 보정 모델이 생성한 local rotation 정보를 합쳐 최종 결과물로 리턴 - 정량지표 (foot skating, MSE) 기반 PoC → 고도화 의사결정 - '얼마나 자연스러운가?' 를 수치화할 수 있는 대표 지표를 선정해 리포트 작성, 의사결정을 위한 지표로 제공 - 가벼운 구조와 1-step sampling의 이점을 살릴 수 있는 1D Convolution 기반 RQVAE를 최종 아키텍쳐 구조로 선택 - Triton Ensemble을 이용해 기존 모델의 후처리 로직을 담당하도록 파이프라인 설계 및 배포

📍 기여한 점

- VQVAE 대비 test set에서 복원 모션과 원본 모션 간 MSE 43.6% 감소 - 호환성 있는 아키텍쳐와 서빙 로직 제안으로 조직 내 생산성 향상 및 유지보수 cost 감소에 기여
