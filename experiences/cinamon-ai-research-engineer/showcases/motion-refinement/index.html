🪄 Motion Refinement

모션의 콘텐츠를 유지하며 어색함을 자연스럽게 보정합니다.

- 생성 또는 합성된 모션에서 남는 떨림, 미끄러짐, 불연속성을 후처리로 보정합니다. - 원본 모션의 타이밍과 동작 의미를 유지하면서 결과의 자연스러움을 높이는 것이 핵심입니다. - 아래 미디어에서 refinement 결과와 실제 사용 흐름을 함께 확인할 수 있습니다.

Refinement 적용 후 더 자연스러워진 모션 결과를 확인할 수 있습니다.

📍 풀어야 했던 문제

- As-is : 생성 또는 합성된 모션 결과에 작은 떨림, 발 미끄러짐, 관절 충돌 같은 아티팩트가 남을 수 있음 - 결과물의 완성도를 떨어뜨리고 후속 수작업 보정 비용을 증가시킴 - 모션의 의미와 타이밍은 유지한 채 품질만 개선해야 함 - To-be : 후처리 단계에서 자연스러움을 안정적으로 향상 - 입력 길이와 동작 유형이 달라도 일관되게 보정 가능해야 함 - 기존 생성 파이프라인에 쉽게 연결 가능한 refinement 단계가 필요

📍 업무 수행 내용

- 대표적인 artifact 유형을 분류하고 전후 비교 기준을 정의 - 원본 motion content를 유지하면서 불연속성을 줄이는 refinement 로직을 적용 - 입력 모션의 흐름과 타이밍이 깨지지 않도록 보정 기준을 설계 - 결과를 서비스 파이프라인에 연결해 생성 직후 후처리가 가능하도록 구성

📍 기여한 점

- 별도 수작업 없이도 생성 결과물의 완성도를 높일 수 있는 품질 보정 레이어를 마련 - 서비스 품질에 직접 연결되는 후처리 단계로 활용 가능 - 다른 생성/합성 기능에도 재사용 가능한 구조를 확보 - 연구 결과를 실제 사용자 경험 개선으로 이어지게 만드는 마무리 단계를 담당 - 모션 품질 이슈를 시각적으로 설명하고 협업할 수 있는 기준을 정리 - 결과 검토와 개선 사이클을 더 빠르게 돌릴 수 있게 기여
