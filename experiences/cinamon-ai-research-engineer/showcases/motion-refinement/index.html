🪄 Motion Refinement

프로젝트 기간: 2025. 12 - 2026. 01

Text-to-Motion 등 기존 모션 생성 결과의 foot skating과 penetration 아티팩트를 줄이기 위해 재사용 가능한 motion refinement 모델을 설계했습니다. VQVAE, RQVAE, diffusion 기반 후보를 비교하고 local rotation 중심 tokenizer와 Triton Ensemble 서빙 구조를 구성해 여러 생성 모델에 공통 적용 가능한 후처리 모듈로 정리했습니다. 그 결과 test set 기준 MSE를 43.6% 낮추고 유지보수 비용을 줄였습니다.

📍 풀어야 했던 문제

- As-is : 생성 모델을 활용한 모션 결과물에는 신체가 겹치거나 떨림이 발생하는 등 아티팩트가 존재했습니다. - 학습 분포에서 먼 local rotation 정보가 생성되면 몰입을 해치는 결과가 발생할 수 있음 - 서비스 중인 개별 모션 모델의 아티팩트를 각각 수정하는 방식은 장기적인 유지보수 비용과 복잡도가 큼 - To-be : 기존 모델과 호환 가능한 모듈형 모션 보정 모델이 필요했습니다. - 학습 범위를 local rotation으로 한정한 motion tokenizer 형태의 보정 모델이 필요함 - 빠른 샘플링과 가벼운 아키텍처를 바탕으로 기존 모델의 후처리 로직에 바로 활용 가능해야 함

📍 업무 수행 내용

- VQVAE, RQVAE, diffusion 기반 모션 보정 모델 PoC를 진행해 입력 모션을 자연스러운 분포로 보정하는 접근을 비교했습니다. - VAE 계열에서는 1D Convolution 경계 구간의 drift를 완화하기 위해 padding을 적용하고, encoder-decoder를 통과한 뒤 padding 구간을 제거해 반환했습니다. - Diffusion 계열에서는 입력 모션에 약한 gaussian noise를 더한 뒤 10 step denoising을 반복해 결과를 반환했습니다. - 모션 canonicalization과 local rotation tokenization 파이프라인을 설계했습니다. - 모션 생성 결과의 어색함이 global translation보다 local rotation에서 주로 발생한다는 가정 아래, 모델이 local 정보만 안정적으로 학습하도록 유도했습니다. - 예) Blender 좌표계 기준으로 'y축으로 2m 걷기'와 '-y축으로 2m 걷기'를 별도 학습 대상이 아니라 동일한 '걷기' 포즈 정보로 더 효과적으로 학습하도록 구성 - 추론 시에는 원본 모션의 pelvis joint translation을 유지하고, 보정 모델이 생성한 local rotation 정보를 결합해 최종 결과를 반환했습니다. - 정량지표인 foot skating과 MSE를 기반으로 PoC를 평가하고 고도화 방향을 결정했습니다. - '얼마나 자연스러운가'를 수치화할 수 있는 대표 지표를 선정해 리포트를 작성하고 의사결정 근거로 제공했습니다. - 가벼운 구조와 1-step sampling의 이점을 살릴 수 있는 1D Convolution 기반 RQVAE를 최종 아키텍처로 선택했습니다. - Triton Ensemble을 이용해 기존 모델의 후처리 로직을 담당하는 파이프라인을 설계하고 배포했습니다.

📍 기여한 점

- VQVAE 대비 test set에서 복원 모션과 원본 모션 간 MSE를 43.6% 낮췄습니다. - 여러 모션 생성 모델에 재사용 가능한 아키텍처와 서빙 로직을 제안해 조직 내 생산성을 높이고 유지보수 비용을 줄이는 데 기여했습니다.
