텍스트 조건으로 ==원하는 길이==의 3D 모션 시퀀스를 생성하는 ==diffusion 기반 text-to-motion 시스템==을 설계하고 배포했습니다. Triton과 FastAPI를 이용한 모델 최적화와 서빙으로 ==기존 대비 10배 빠른 추론 속도==를 달성했습니다. 데이터, 모델 학습, 최적화, 배포, 서비스 연동에 이르는 ==ML lifecycle을 직접 운용==했습니다.

- 생성 결과물의 foot skating, penetration을 개선하기 위해 generation → refinement 2단계 로직을 설계했습니다. - 이전 프로젝트의 결과물인 motion refinement model을 이용해 개별 모델의 재사용성을 높였습니다. - 텍스트 정합성을 고려한 mirror augmentation으로 모션-텍스트 데이터 쌍을 증강하고 학습에 활용했습니다. (모션 데이터 ==2배==, 텍스트 어노테이션 데이터 ==30% 증가==) - DDPM 1000 step → DDIM 10 step으로 샘플링을 간소화해 추론 시간을 단축했습니다. - ==Triton과 FastAPI==를 결합한 서빙 구조를 채택해 추론 최적화와 서비스 I/O를 분리했습니다. - Dynamic batching을 적용해 ==GPU 자원 활용을 최적화==했습니다. - Ensemble model을 적용해 단일 Triton 서버 호출로 2단계 추론 파이프라인을 단순화했습니다. - 사내 모션 모델 데모 페이지에 API를 연동해 프로젝트 결과를 사용 가능한 형태로 조직 구성원에게 공유했습니다.
