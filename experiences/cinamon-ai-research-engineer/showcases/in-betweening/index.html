🎥 In-betweening

프로젝트 기간: 2025. 06 - 2025. 11

임의의 시작/종료 포즈 사이를 자연스럽게 연결하는 motion in-betweening 모델을 고도화했습니다. - Baseline in-betweening model의 failure case 시나리오를 재현해 비교 케이스를 확보했습니다. - Diffusion noise optimization 기법을 사용해 안정적이고 자연스러운 in-betweening 모델을 확보했습니다. - 사내 데모 페이지에 모델을 통합해 사용 가능한 형태로 배포했으며, 데모 쇼케이스를 제공했습니다.

기존 시작/종료 구간 사이를 자연스럽게 메우는 transition 결과를 확인할 수 있습니다.

📍 풀어야 했던 문제

- As-is : baseline 모델은 짧은 거리, intro/outro가 유사한 경우에 아티팩트 발생 - 짧은 거리 이동시 drifting 후 이동하는 부자연스러운 전환 모션이 생성됨 - 모션의 역동성 대비 긴 연결 시간이 주어지는 경우 부자연스러운 전환 모션이 생성됨 - To-be : 자연스러운 전환 모션을 생성하는 motion in-betweening 모델 확보 - 짧은 거리를 이동하거나, 긴 연결 시간이 주어지는 경우에도 자연스러운 전환 모션을 생성할 수 있는 모델 필요 - 임의의 intro/outro 모션에도 자연스러운 전환 모션을 생성할 수 있는 모델 필요 - 실시간 추론이 가능한 baseline 모델의 latency를 최대한 유지하며 서빙할 수 있어야 함

📍 업무 수행 내용

- Baseline model의 failure case 확보 및 분석 리포트 작성 - 거리, 길이, endpoint 유사도, 속도 변화에 따라 실패 케이스를 분류 - Short move / long move / similar endpoint에서의 전환 모션 차이를 비교 - 작성한 리포트를 바탕으로 고도화 모델에서 개선이 필요한 구체적인 문제 정의 - Diffusion noise optimization 기반 품질 개선 - Pretrained diffusion prior를 이용, 샘플링 시 최적화 기법 적용 - Intro/outro motion을 제약으로 두고, 나머지 시퀀스를 랜덤 노이즈로부터 시작 - 지정한 최적화 횟수만큼 디노이징을 반복하며 원본 intro/outro 정보와 MSE loss를 줄이는 방향으로 초기 노이즈를 업데이트 - 다양한 이동 시나리오에서도 자연스러운 이동 모션이 생성됨 (Media 3) - TorchServe 기반 모델 서빙 및 데모 페이지/쇼케이스 제작 - 성능-속도 간 trade-off를 고려한 optimize step 400 설정, 샘플 1개당 소요 시간 약 30초 소요 - 이후 진행한 프로젝트에서는 Triton + FastAPI 기반 서빙 로직 적용

📍 기여한 점

- 최적화 기반 motion in-betweening 샘플링 로직 적용, 기존 baseline model의 failure case 해소 - Pretrained diffusion model의 prior knowledge를 이용, 유지보수에 필요한 cost 감소 - Baseline과 비교 가능한 성능 리포트를 작성해 의사결정을 위한 근거 자료 제공 - Failure case 개선 쇼케이스, API 호출을 통한 모델 추론 데모 제공
