📍 풀어야 했던 문제

- As-is : 복잡한 프롬프트를 생성/검색 모델에 사용하는 경우 motion-text align이 감소, 안정적으로 표현 가능한 범위가 축소되는 문제 발생 - 방향 전환, 세부 gesture, body-part constraint가 함께 있는 프롬프트에서 제어력이 급격히 떨어짐 - To-be : part-aware decomposition + retrieval + composition 파이프라인 제안 - 파트별 의미를 안정적으로 분리하는 LLM 기반 prompt refinement - 검색 모델을 이용해 상하체별 모션 검색 결과를 단순 접합 - 단순 접합시 발생하는 아티팩트는 보정 모델을 통과해 자연스러운 모션으로 제공

📍 업무 수행 내용

- 테스트용 프롬프트 리스트를 만들어 세부 검증 마일스톤 설계 및 검증 수행 - RQ1 : LLM이 파츠별 의미를 잘 분리하는가 - RQ2 : 분리된 파트 정보로 적절한 motion retrieval이 가능한가 - RQ3 : 임의 합성한 결과를 별도 refinement 네트워크를 이용해 자연스럽게 만들 수 있는가 - 검색 모델 데이터셋 구축에 사용한 VLM prompt 분석 → facial expression을 제외하고 저수준, 구체적인 방향으로 propmt refine을 진행하도록 system propmt 작성 - 예) 'Raise one hand and check the time on the watch' 에 대한 검색용 prompt refinement - UpperBody: The person lifts their left arm and turns the wrist slightly. - LowerBody: The person stands still with legs relaxed and feet firmly on the ground. - 분리된 상/하체 prompt로 각각 모션 검색 → joint별 local rotation 정보를 단순 접합하는 방식으로 compose - 1-step denoising으로 motion refinement 적용, 모션 보정 모델의 독립 모듈화 가능성 검증

📍 기여한 점

- 복합 프롬프트 문제를 하나의 end-to-end 문제가 아닌, 조합 가능한 파이프라인 문제로 재구성 - 디버깅 포인트와 개선 우선순위를 명확히 확인 가능 - PoC 파이프라인을 구성하는 마일스톤을 독립적인 사내 모션 AI 연구 자산으로 활용해 조직 생산성 향상에 기여 - 컨셉 검증을 위한 빠른 PoC에서 기존 모델을 조합해 시너지를 낼 수 있는 실용적 경로를 제안 - 모델 재사용성과 실험 속도를 동시에 높일 수 있는 방향 제시
