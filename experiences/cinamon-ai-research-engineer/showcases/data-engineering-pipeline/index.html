🛠️ Data Engineering Pipeline

프로젝트 기간: 2025. 05 - 2026. 01 (상시 진행)

모션 생성 모델 학습에 필요한 데이터 전처리와 품질 검증 파이프라인을 자동화해 수동 작업에 의존하던 운영 병목을 해소했습니다. Airflow 기반 스케줄링, rule-based motion 필터링, 대시보드 구축까지 담당하며 학습 데이터 품질과 팀 생산성을 함께 개선했습니다. 그 결과 제외되던 데이터를 재편입해 데이터셋 규모를 약 30% 늘리고 정기 전처리 운영 체계를 정착시켰습니다.

전처리, filtering, metadata, canonicalize가 연결된 운영 파이프라인 구조를 한눈에 보여줍니다.

📍 풀어야 했던 문제

- As-is : 모션 캡처 데이터는 정기적으로 추가되지만, 모델 학습에 사용하는 전처리와 품질 검증은 수동으로 운영되고 있었습니다. - 정기적인 데이터 추가가 점진적인 모델 성능 개선으로 바로 이어지지 않음 - 담당자가 수동으로 전처리 스크립트를 실행해 담당자 의존성이 매우 높음 - 품질을 저해하는 데이터가 학습에 포함되면 반복적으로 아티팩트를 만들어 운영 비용이 증가함 - 폴리싱이 끝났지만 학습에 포함되지 않은 데이터를 데이터셋에 재편입할 필요가 있음 - To-be : 신뢰할 수 있는 데이터 전처리 자동화 파이프라인이 필요했습니다. - 정기적인 데이터 업데이트와 자동화로 운영 비용을 줄이고, 데이터 추가와 모델 성능 개선 시점 간 간격을 좁혀야 함 - 실제 모션 데이터를 로드해 학습용 데이터 포함 여부를 검증하는 rule-based 필터링 로직이 필요함

📍 업무 수행 내용

- 초기에는 Dagster로 검증하고, 이후 Airflow 기반 운영 파이프라인으로 전환해 데이터 전처리를 자동화했습니다. - Timetable 기능을 활용한 커스텀 데이터 스케줄링을 적용했습니다. - 수동 trigger 시 10시간 이상 소요되던 전처리 작업을 매달 마지막 주 주말 오전에 자동 수행하도록 구성했습니다. - 모션 데이터 필터링 공통 로직을 개발했습니다. - foot sinking/plunging 탐지 - 비정상적인 height spike 탐지 - 유효 공간(valid space) 이탈 탐지 - hovering motion 탐지 - 애니메이터와 협업해 학습 가능한 수준의 모션 데이터 품질 기준과 keyframe 규칙을 명세화했습니다. - AI Lab 구성원 대상 데이터 전처리 프로세스 세미나를 기획하고 진행했으며, 관련 내용을 문서화했습니다. - 데이터 전처리 결과를 실시간으로 확인할 수 있는 대시보드를 제작하고 배포했습니다.

📍 기여한 점

- 데이터 파이프라인을 자동화된 운영 체계로 정리해 담당자 의존성을 줄였습니다. - 세부 전처리 로직과 진행 상황을 여러 구성원이 자유롭게 확인할 수 있게 했습니다. - 휴일에 자동 전처리를 수행하고 주중에는 모델 설계와 학습에 집중할 수 있도록 스케줄러를 구성해 팀 업무 효율을 높였습니다. - 사내 모션 모델이 공통으로 사용하는 데이터 품질 기준을 정리했습니다. - 메타데이터 기반 필터링과 rule-based 모션 필터링의 2중 구조로 아티팩트를 유발할 수 있는 데이터를 일관된 기준으로 제거했습니다. - sparse keyframe으로 분류돼 제외되던 데이터를 재편입해 데이터셋 규모를 약 30% 늘렸습니다.
