프로젝트 기간: 2025. 05 - 2026. 01 (상시 진행)

모델 학습용 데이터 전처리를 Airflow 기반으로 자동화/모니터링 가능하도록 운영 파이프라인을 개선했습니다. 데이터 시트와 모션 검증 로직을 개선해 아티팩트를 유발할 수 있는 모션 데이터를 학습용 데이터에서 제거했습니다. - 수동 전처리 스크립트 실행으로 인한 모델 학습 지연 병목을 없애 업무 생산성에 기여했습니다. - 학습에 사용되는 일부 OOD 데이터의 문제점을 발견, 실제 모션 데이터를 읽어 서비스 시나리오에 맞는 추가 필터링 로직을 적용했습니다.

📍 풀어야 했던 문제

- As-is : 모션캡쳐 데이터 추가는 정기적이나, 모델에 사용하는 데이터 전처리는 정기적으로 이루어지지 않음. 모션 모델의 품질 일관성을 유지하기 위한 데이터 필터링 로직 필요 - 정기적인 데이터 추가가 점진적 모델 성능 개선으로 이어지지 않음 - 담당자가 수동으로 전처리 스크립트를 실행하는 방식으로, 담당자 의존성이 매우 높음 - 모션 모델의 품질을 저해하는 일부 케이스 존재 → 해당 데이터로 학습한 모델이 반복적으로 아티팩트를 만들어 운영 cost 증가 - 폴리싱이 완료되었으나 학습에 포함되지 않은 데이터를 학습 데이터셋에 추가 필요 - To-be : 신뢰 가능한 데이터 전처리 자동화 파이프라인 확보 - 정기적인 데이터 업데이트 및 자동화로 운영 cost 감소, 데이터 추가와 모델 성능 개선 시점 간극 감소 - 모션 데이터를 로드해 학습용 데이터에 포함 가능한지를 검증하는 rule-based 데이터 필터링 클래스 개발

📍 업무 수행 내용

- Dagster (임시), Airflow 기반 데이터 전처리 자동화 파이프라인 확보 - Timetable 기능을 활용한 커스텀 데이터 스케줄링 적용 - 수동 trigger 시 10시간 이상 소요되는 전처리 작업을 매달 마지막 주 주말 오전에 수행하도록 자동화 - 모션 데이터 필터링 공통 로직 개발 - foot sinking/plunging 탐지 - 비정상 height spike 탐지 - valid space 이탈 탐지 - hovering motion 탐지 - 애니메이터와 협업을 통해 학습 가능한 수준의 모션 데이터 품질 기준(keyframe) 명세화 - AI Lab 구성원 대상 데이터 전처리 프로세스 세미나 기획 및 진행, 문서화 - 데이터 전처리 결과를 실시간으로 확인할 수 있는 대시보드 제작 및 배포

📍 기여한 점

- 데이터 파이프라인을 자동화된 운영 방식으로 정리 - 담당자 의존성 제거, 세부 전처리 로직과 진행 상황을 구성원이 자유롭게 확인 가능 - 휴일에 자동으로 전처리를 수행하고 주중에 모델 설계 및 학습을 진행할 수 있도록 스케줄러 구성, 구성원 업무 효율성 향상에 기여 - 사내 모션 모델이 공통적으로 사용하는 모션 데이터의 품질 기준 작성 - 메타데이터 기반 필터링 - rule-based 모션 필터링 2중 구조로 아티팩트를 발생시킬 수 있는 데이터를 일관된 기준으로 제거 - Sparse keyframe으로 탐지되어 학습에서 제외되었던 데이터를 포함, 데이터셋 규모 약 30% 증가
