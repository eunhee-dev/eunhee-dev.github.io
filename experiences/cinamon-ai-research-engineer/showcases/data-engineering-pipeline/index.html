학습용 데이터가 처리되는 전체 파이프라인 구조를 한눈에 보여줍니다.

📍 풀어야 했던 문제

- As-is : 원천 데이터 포맷이 제각각이라 학습 전 반복 전처리와 수동 검수가 필요 - 데이터 정합성 오류가 늦게 발견되면 학습 비용이 커짐 - 사람 의존적인 프로세스라 재현성과 처리 속도가 떨어짐 - To-be : 학습용 데이터 파이프라인 자동화 - 표준화된 포맷 변환이 필요 - 검수 포인트와 실패 지점을 추적할 수 있어야 함

📍 업무 수행 내용

- raw data ingest부터 training-ready asset 생성까지 단계별 파이프라인을 구성 - 전처리, 검증, 산출물 관리 로직을 반복 실행 가능한 구조로 자동화 - 운영 관점에서 필요한 logging과 check point를 정리 - 전체 흐름을 빠르게 이해할 수 있도록 파이프라인 다이어그램을 구성

📍 기여한 점

- 데이터 준비 시간을 줄이고 반복 작업을 자동화해 연구 개발 속도 향상에 기여 - 학습 입력 품질과 재현성을 높일 수 있음 - 동일한 기준으로 데이터를 관리할 수 있는 운영 기반 마련 - 데이터 엔지니어링 관점의 병목을 구조적으로 해결할 수 있는 흐름을 정리 - 팀 간 협업 시 파이프라인 이해도를 높일 수 있음 - 후속 모델 실험이 더 빠르게 이어질 수 있는 기반을 제공
